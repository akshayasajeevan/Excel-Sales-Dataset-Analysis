# Sales Data Analysis using Excel

## Project Overview

This project focuses on analyzing a sales dataset using **Microsoft Excel**.

The dataset was organized into customer, store, product, and sales tables. Excel functions, analysis tools, PivotTables, and dashboards were used to transform the data into meaningful business insights.

## Dataset Structure

The project contains:

* Customer Dimension
* Store Dimension
* Product Dimension
* Sales Fact Table
* Analysis Sheet
* Pivot Tables
* Dashboard

## Key Tasks

* Worked with multiple related datasets
* Handled missing values in product cost
* Used `VLOOKUP` to retrieve related customer, product, and store information
* Created calculated fields
* Performed descriptive analysis
* Created PivotTables
* Analyzed sales by region, product, customer, and store
* Created a sales dashboard

## Tools Used

* Microsoft Excel
* VLOOKUP
* IF & ISBLANK
* PivotTables
* Analysis ToolPak
* Excel Dashboard

## Skills Demonstrated

* Data Cleaning
* Data Transformation
* Lookup Functions
